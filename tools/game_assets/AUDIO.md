# VetroMania audio toolkit

All audio under `game/assets/audio/` is original procedural synthesis generated by `tools/game_assets/audio.py`. No recorded samples are used; every WAV is built from deterministic NumPy synthesis with fixed seeds.

## Regenerating

From the repository root:

```sh
python tools/game_assets/audio.py
```

Custom output path:

```sh
python tools/game_assets/audio.py --out game/assets/audio
```

Determinism check against the committed tree (CI runs this on Linux):

```sh
python tools/game_assets/audio.py --check
```

## Manifest schema

`game/assets/audio/manifest.json` is UTF-8 JSON with sorted keys and this shape:

```json
{
  "version": 1,
  "sfx": {
    "jump": {
      "file": "sfx/jump.wav",
      "volume_db": 0.0
    }
  },
  "music": {
    "crash_site": {
      "file": "music/crash_site.wav",
      "loop_begin": 0,
      "loop_end": 1280000,
      "volume_db": -6.0,
      "bpm": 96
    }
  }
}
```

Runtime should apply loop settings from the manifest on `AudioStreamWAV` (`loop_mode = AudioStreamWAV.LOOP_FORWARD`, `loop_begin`, `loop_end`) because the manifest is the authoritative loop-point source.
